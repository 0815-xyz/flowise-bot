# flowise-bot
Dieses Repository dient ausschließlich als Host für die Datei meinbot.js,
damit sie mit <script type="module" src="https://0815-xyz.github.io/flowise-bot/meinbot.js"></script>
in Moodle-Textblöcke eingebunden werden kann. 
Das Script lädt automatisch den Flowise-Embed-Client und initialisiert den Chatbot
mit der angegebenen Chatflow-ID.
